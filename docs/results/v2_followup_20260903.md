## 1. 延迟长尾的修复与效果

三个 runtime 原先每次请求创建、释放 `ggml_gallocr`，反复分配/释放 GPU 图缓冲区。
修复将 allocator 交给模型对象持有；每次仍建立当前计算图，分配器复用容量并按需要扩容，
模型销毁时释放。不是缓存上一请求的动作。同步读回动作后才结束计时。
这项生命周期改动在十个测试配置中保持修复前后动作文件逐字节一致。

单卡 RTX 4090、固定原始 CPU 观测至完整 CPU 动作块；双侧含预处理、传输、读回，
C++ 另含公开 ZMQ。排除模拟器、队列回放、模型加载；5 次预热、100 次计时，
显存另以 20 次不计时请求采样。XR0 双侧 BF16 policy + F16 vision，TurboVLA 双侧 BF16。

## 2. 补齐 TurboVLA 同机公共闭环对照

使用官方 Python 模型接入**同一个** `LIBEROSimAdapter` 和 `run_one_task`，
不是声称跑通上游独立 `evaluate` CLI。既有 Python control20 与本次 C++ 重跑：
同卡 RTX 4090 GPU 2、同权重、seed 42、spatial task 0/4、每项 10 回合、
原生双视角 256px、12 步动作回放、relative 控制、10 个等待步、不录视频。

| 实现 | 成功回合 | 环境步数 | 按步数加权的 get_action ms/step |
|---|---:|---:|---:|
| C++ | 20/20 | 2049 | 2.147 |
| Python 官方模型 / 公共闭环 | 20/20 | 2061 | 3.637 |

C++ 耗时约低 **41%**。计时均为公共 `get_action()`，包含队列回放与已完成的动作读回，
不含 `env.step()` 或模型加载；首个推理请求计入。按每回合的
`environment_steps × average_step_ms` 求和后除以总步数，episode 平均值原本只保留

不同轨迹步数、仅两项 task、非交错多轮测速，不能推广为全套 LIBERO 加速比。

## 3. 撤回 V2 交接中三条不成立的 X-VLA 结论

1. **现存 HF 不是历史 GGUF 的同权重来源。** 按生产转换器映射比较 902 个张量，
   仅 1 个完全相同、901 个不同；两侧均无非有限值。另绕开数组数值视图，直接读取
   safetensors/GGUF 文件偏移处的 F32 bias 字节，三个独立抽查都不同。
   “872/902 一致、其余只是读取伪影”不成立。
2. **没有复现生产转换器产生 30 个 NaN bias。** 本次只读转换审计输出全有限；
   不恢复使用可疑旧产物，但不能据先前误读认定转换器存在该缺陷。
3. **115.9 ms 和 9790 MiB 不能构成 X-VLA 对照。** `/tmp/xvla_py_bench.py`
   只有 2 次预热、20 次 FP32 前向；预处理/上传在计时外且无 CPU 动作读回。
   日志记录的是 PyTorch allocator 峰值 3.437 GiB，不是进程采样 9790 MiB。
   后者属于 XR0 Python。另 `outputs/bench_fixed_20260903/xvla-f32.server.log`
   明确显示 `matmul=BF16`，不能将文件名为 f32 的这次短测称为 F32 计算。

## 4. 修复真正生效的 episode noise opt-in

此前入口调用 `reset(noise_seed=derived)`，但 XR0/X-VLA 专用路径仍无条件使用观测哈希，
记录的种子与实际噪声来源不一致。本次仅修改客户端、公共入口与集成测试：

- 显式 `reset(noise_seed=...)` 后，XR0/X-VLA 使用该回合 RNG 生成连续的
  float32 `[chunk, state_dim]` 噪声；同种子可重放整个请求序列。
- `reset()` 保留旧观测哈希协议；显式 `observations.action_noise` 仍优先。
- `--derive-episode-noise` 要求非负 `--noise-seed`；TurboVLA 是确定性 ACT、
  没有 action-noise 输入，LingBot 使用独立噪声选项，两者拒绝此不适用开关。
  pi0.5/GR00T 的当前公共客户端也未配置该噪声生成入口，拒绝此新开关而非记录虚假生效。
- `result.json` 记录该开关。SmolVLA 原有自动派生逻辑不变；历史默认评测不被改写。

公共集成测试 33/33 通过，包括实际请求 noise 数组、不同种子、同种子重放、默认兼容、
显式输入优先、CLI 错误、episode 记录；并更新了默认渲染已为 256 的过期测试断言。
相邻汇总、量化、参考模型与工具测试另 13/13 通过，合计 46 项，无跳过。
这证明客户端协议，不冒充新噪声协议下三模型全套成功率验收。
另修正 `.gitignore` 中结果目录例外的顺序：此前被后面的 `docs/*` 覆盖，导致新报告
静默被忽略；现有文档目录结构不变，新增审计报告和证据会正常出现在待提交列表中。
