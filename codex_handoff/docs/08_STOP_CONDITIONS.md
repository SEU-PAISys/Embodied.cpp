# 停止条件与求助条件

## Codex 必须停止并请求确认

- 需要 `sudo`；
- 需要安装/卸载系统包；
- 需要修改驱动、CUDA、系统 Python；
- 需要联网下载模型或大文件；
- 需要写出仓库工作区；
- 需要修改超过三个源文件；
- 需要删除文件；
- 需要改 third_party/submodule；
- 需要运行预计超过 30 分钟的命令；
- 需要占用大量 GPU/磁盘；
- 需要改变公开 API；
- 需要执行 destructive Git 命令；
- 测试失败但原因不清楚；
- 发现仓库已有未提交改动。

## 使用者应向学长/老师求助

- 权重或数据访问受限；
- 项目 README 与组内分支明显不一致；
- 需要特定 NPU/机器人硬件；
- 任务目标一直是“帮忙写代码”但没有研究问题；
- 两周仍没有明确指导人和验收标准；
- 计划发布代码但知识产权不清楚；
- 论文署名、保密或横向项目要求不清楚；
- 需要几百 GPU 小时或超出本机资源。
